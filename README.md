# dan-reisinger-site

אתר מתנות אמנות לארגונים עם הדפסי דן ריזינגר. משאבי אנוש מגדירים הזמנה, ועובדים בוחרים כרזה עם קוד התחברות.

- Framework: TanStack Start + React + Tailwind CSS
- Data & auth: Supabase (own project)
- Hosting: Vercel (every push to `main` updates the live site)

Originally created in Lovable; now fully independent of it.
